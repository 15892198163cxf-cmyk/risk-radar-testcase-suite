# 用例生成 Prompt 模板 v1

## 用途
当需要根据需求分析结果生成测试用例时，参考此模板的结构和逻辑。

## 生成流程

### 输入
- 需求原文
- 功能点列表 (FP)
- 约束条件
- 关联关系
- 命中的知识库规则（如有）

### 生成逻辑

```
对每个 FP:
  1. 确定 FP 类型 → 查覆盖策略矩阵
  2. 生成必选覆盖用例
  3. 生成推荐覆盖用例
  4. 如有命中规则 → 根据规则补充特定用例

对关联层:
  1. 数据流关联 → 生成集成用例
  2. 不变量 → 生成校验用例
  3. 生命周期 → 生成 E2E 用例
```

### 用例编写要求

每个用例包含:
- **TC-ID**: 编号（TC-001, TC-002, ...）
- **标题**: [主体]+[动作]+[条件]+[预期] 格式
- **关联 FP**: 追溯到哪个功能点
- **优先级**: P0/P1/P2
- **前置条件**: 测试前需要准备什么
- **步骤**: 具体操作步骤（每步一个动作）
- **预期结果**: 具体的、可验证的期望结果
- **测试类型**: 正向/异常/边界/权限/集成

### 用例质量检查清单

生成后自检:
- [ ] 每个 FP 至少有 1 个正向用例
- [ ] 约束条件都有对应的异常用例
- [ ] 状态变更有完整的状态流转用例
- [ ] 用例标题清晰可读
- [ ] 步骤具体，包含测试数据
- [ ] 预期结果可验证，不模糊
- [ ] 按业务场景组织，不按技术模块
- [ ] 用例间无重复
